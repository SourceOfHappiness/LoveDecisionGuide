## 核心方法论与理论支柱

1. **关系递进六阶段模型（遵循社会渗透规律）**：
   - `初识阶段` ➔ `熟悉阶段` ➔ `吸引阶段（自我成长与生活热爱）` ➔ `追求与确认` ➔ `亲密阶段` ➔ `长期相处阶段`。
   - 坚决杜绝“未吸引先表白”造成的情感压迫，以及“毫无底线讨好”导致的自我损耗。
2. **依恋心理学与情绪成熟度**：
   - 识别焦虑型、回避型与安全型依恋模式；
   - 告别自卑自证，理解伴侣的安全感试探，以从容、稳定与确定感建立信任。
3. **戈特曼末日四骑士与 5:1 黄金比**：
   - 根除亲密关系最大的四种致命毒素：批评、蔑视、辩解、冷战；
   - 建立睡前清零契约与暂停冷静机制，维护健康平等的亲密战友同盟。
4. **知情同意与边界伦理（Affirmative Consent）**：
   - 彻底摒弃传统 PUA 的肢体试探糟粕；
   - 任何身体与心理亲密，均建立在绝对尊重对方身体自主权与双向奔赴的前提下。
