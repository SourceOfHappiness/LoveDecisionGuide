## 四大核心支柱

1. **恋爱六阶段模型（严格循序渐进）**：
   - `认识阶段` ➔ `熟悉阶段` ➔ `吸引阶段（占60%精力）` ➔ `追求阶段` ➔ `诱惑阶段` ➔ `长期相处阶段`。
   - 彻底破除“未吸引先表白”导致的表白死、以及“盲目付出”导致的备胎好人卡。
2. **两性底层心智模型**：
   - 生存价值（猎人潜质：事业、审美、身材、自律）与情绪保障（靠谱专一、共情）双核驱动；
   - 坚持“提供价值”而非“索取价值”，树立清晰的自我原则（Boundary）。
3. **聊天工程化（三维发散法）**：
   - 杜绝连续发问（查户口）、疯狂斗图与长篇大论；
   - 掌握关键词法、联想法与感受评价法，彻底解决脑内空白。
4. **线下约会与升级阶梯**：
   - 动态多节点转场（Venue Bouncing），用心理时间加速信任建立；
   - 进退自如的肢体触碰阶梯（Kino Escalation），不突兀、不猥琐、不尴尬。
