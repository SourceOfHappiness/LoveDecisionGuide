## 核心方法论与理论支柱

1. **关系递进六阶段模型（遵循社会渗透规律）**：
   - `初识阶段` ➔ `熟悉阶段` ➔ `吸引阶段（自我成长与生活热爱）` ➔ `追求与确认` ➔ `亲密阶段` ➔ `长期相处阶段`。
   - 坚决杜绝“未吸引先表白”造成的情感压迫，以及“毫无底线讨好”导致的自我损耗。
2. **三维成本与性价比量化模型（HowToLiveBetter 范式）**：
   - **花钱**：`不花钱`（0 元）/ `花少量钱`；
   - **花时间**：`顺手`（5 分钟内）/ `花几小时` / `长期坚持`；
   - **要毅力**：`不用毅力` / `要一点毅力` / `要很多毅力`；
   - **综合性价比**：根据成本权重与收益层级加权测算 `极高` / `高` / `一般`。
3. **依恋心理学与戈特曼婚恋科学**：
   - 识别焦虑型、回避型与安全型依恋模式；
   - 根除亲密关系四大毒素（批评、蔑视、辩解、冷战），践行 5:1 情感账户与睡前清零契约。
4. **民法典法治与人身避险铠甲**：
   - 严格依据《中华人民共和国民法典》第一千零六十二至一千零六十四条、最高人民法院涉彩礼司法解释（法释〔2024〕1号）与反家庭暴力法；
   - 筑牢转账借贷留痕、婚前房产协议、共债共签隔离、反家暴六大证据链与重大疾病婚检知情权防线。

## 本地维护与自动化部署

### 重新编译数据
若对 `book/` 下的 Markdown 条目进行了新增或修订，运行以下命令即可重新编译检索数据：

```bash
python tools/build_index.py
```

构建脚本会自动提取条目中的属性与成本标签，计算性价比，并安全注入 `index.html` 中的 `#embedded-data` 标签，实现 100% 离线免服务端可用。

### GitHub Actions 持续部署
项目已配置 `.github/workflows/deploy.yml`，每次向 `main` 分支提交代码时，GitHub Actions 将自动执行 Python 构建测试并一键发布至 GitHub Pages。
